# Bootstrap a repo with the SmartPangolin secret standard

    ./pangolin-bootstrap.sh        # macOS / Linux
    .\pangolin-bootstrap.ps1       # Windows

Creates the standardized `.secret/` safe-zone (git-ignored, never shared), a
starter `.pangolin.json`, and the right `.gitignore` entries — so every repo in
your org uses the same predictable, scannable layout.
