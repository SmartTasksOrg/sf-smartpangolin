# pangolin-check (PHP)

Native PHP port (PCRE). No Composer dependencies.

```bash
php pangolin-check.php <path> [--mode public|private] [--json] [--no-gitignore]
# exit code is non-zero if any SEC-* finding is present (fails CI)
```

Wire into `composer.json`:
```json
{ "scripts": { "pre-publish": "php vendor/smartpangolin/pangolin-check.php ." } }
```
`policy.json` is regenerated by `python3 tools/export_policy.py`.
